# CineReserve Full Stack Project

## Tech Stack
- Angular
- ASP.NET Core Web API
- SQL Server
- Entity Framework Core
- JWT Authentication

## Features
- Movie booking
- Showtime management
- Admin portal
- JWT login
- Seat selection
- VIP pricing
- Duplicate booking prevention
- Persistent booking system

## Structure

frontend → Angular application

backend → ASP.NET Core API
